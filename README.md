# slicehead

Slice CSV/TSV head tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/slicehead/

## Install / run

```bash
git clone https://github.com/theworker02/slicehead.git
cd slicehead
node src/cli.js
node --test
```
